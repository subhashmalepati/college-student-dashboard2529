# Campus Hub — Student Dashboard

College assignment: Group 2, Project 3 — College Student Dashboard.

Responsive HTML/CSS dashboard concept showing student profile, attendance, sample marks, timetable, subjects, notifications, and announcements. All figures and schedule details are demo data, not actual student records.

## Stack
- HTML5
- CSS3, including responsive media queries

## Run
Open `index.html` in a browser; no build steps are needed.
