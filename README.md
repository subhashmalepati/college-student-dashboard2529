# Campus Hub — Student Dashboard

A clean, modern student dashboard UI concept designed to centralize daily class schedules, semester progress, academic metrics, and campus announcements in one intuitive workspace [0.1.2].

🌐 **Live Demo:** [student-dashboard-sh.vercel.app](https://vercel.app)

---

## ✨ Features

* **Workspace Navigation:** Seamless switching between **Overview**, **Timetable**, **Subjects**, and **Announcements** [0.1.2].
* **Academic Snapshot:** At-a-glance KPI cards displaying overall attendance percentage (`92.4%`), average score (`86/100`), and daily class count [0.1.2].
* **Interactive Daily Timetable:** Time-blocked schedule featuring course titles, room/block locations, and live status indicators (*Completed*, *Up next*, *Upcoming*) [0.1.2].
* **Subject Progress Tracker:** Visual breakdown of semester completion across core subjects (*Programming Foundations*, *Web Development*, *Mathematics*, and *Communication Skills*) [0.1.2].
* **Campus Announcements Feed:** Categorized notice board highlighting upcoming project deadlines, extended campus hours, and student events [0.1.2].

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and accessible layout
* **CSS3:** Responsive grid/flexbox architecture and modern UI styling
* **Deployment:** Hosted on Vercel
